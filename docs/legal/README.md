# Rechtliche und organisatorische Vorlagen

Diese Vorlagen schließen die technischen Lücken nicht durch eine Behauptung, sondern durch prüfbare Dokumente. Sie sind **Entwürfe**, keine Rechtsberatung. Vor Unterzeichnung muss eine rechtskundige Person die konkrete Rolle (Verantwortlicher, Auftragsverarbeiter, gemeinsame Verantwortlichkeit), den Sitz der Parteien und die tatsächlich eingesetzten Unterauftragnehmer prüfen.

## Geltungsbereich

ShieldPM wird selbst betrieben. Der Betreiber der Instanz ist in der Regel der Verantwortliche; der ShieldPM-Maintainer verarbeitet dabei keine Instanzdaten. Ein AVV ist deshalb vor allem dann erforderlich, wenn ein Dienstleister ShieldPM für einen Kunden hostet oder betreibt. Die Vorlagen decken diesen Fall ab und lassen sich auf reine Self-Hosting-Betreiber übertragen.

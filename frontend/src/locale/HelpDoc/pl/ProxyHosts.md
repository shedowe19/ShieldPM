## Czym jest host proxy?

Host proxy to punkt wejściowy dla usługi internetowej, którą chcesz przekierować.

Zapewnia opcjonalne zakończenie SSL dla twojej usługi, która może nie mieć wbudowanej obsługi SSL.

Hosty proxy są najpopularniejszym zastosowaniem ShieldPM

## Kolumny tabeli

Otwórz **Kolumny** po prawej stronie nad tabelą hostów proxy. Pola wyboru pozwalają osobno pokazać lub ukryć ikonę, właściciela, źródło, cel, SSL, dostęp, stan, kontrolę usługi i opóźnienie. Wybór jest zachowywany w tej przeglądarce po odświeżeniu strony. Menu działań pozostaje widoczne; ukrycie kolumny nie zmienia konfiguracji hosta ani monitorowania.

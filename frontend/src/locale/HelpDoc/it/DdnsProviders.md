## Cos'è il DDNS?

Il DNS Dinamico (DDNS) ti permette di aggiornare automaticamente un nome di dominio con il tuo indirizzo IP dinamico e mutevole. Questo assicura che i tuoi servizi rimangano accessibili tramite il tuo nome di dominio anche se il tuo ISP cambia il tuo indirizzo IP.

ShieldPM controlla periodicamente il tuo IP pubblico e aggiorna il tuo provider DNS se viene rilevato un cambiamento.

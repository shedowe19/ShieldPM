## Cos'è un Tunnel Cloudflare?

I tunnel Cloudflare ti permettono di esporre i tuoi servizi locali in modo sicuro senza aprire porte sul tuo firewall o router. Il tuo server stabilisce una connessione in uscita sicura alla rete di Cloudflare.

Questo è altamente consigliato se sei dietro a un CGNAT o non vuoi esporre il tuo indirizzo IP reale.
